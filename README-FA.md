# KAREN WEB V2

نسخه دوم: فروشگاه قالب + حساب کاربری اجباری برای خرید + حساب مالک ثابت KARENONE + پیام‌های ساده پشتیبانی.

## اجرای Termux

```bash
pkg update -y
pkg install nodejs-lts unzip -y
mkdir -p ~/KAREN-WEB
unzip /storage/emulated/0/Download/KAREN-WEB-V2.zip -d ~/KAREN-WEB
cd ~/KAREN-WEB
npm install
cp .env.example .env
nano .env
npm start
```
مرورگر: `http://127.0.0.1:3000`

## Supabase

1. یک پروژه Supabase بساز و محتوای `schema.sql` را در SQL Editor اجرا کن.
2. در Storage یک bucket خصوصی به نام `template-files` بساز.
3. مقدارهای `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` را در `.env` محلی یا Render Environment قرار بده.
4. کلید service-role را هرگز در فایل‌های public یا GitHub عمومی قرار نده.

## حساب مالک

در Render Environment این مقادیر را تنظیم کن:
- `ADMIN_USERNAME=KARENONE`
- `ADMIN_PASSWORD` یک رمز طولانی و محرمانه که فقط مالک نگه می‌دارد.
- `SESSION_SECRET` یک رشته تصادفی طولانی و جدا از رمز مدیر.

پس از اتصال دیتابیس و راه‌اندازی سرور، حساب `KARENONE` به‌صورت خودکار با نقش admin ساخته می‌شود. اگر نام کاربری قبلاً وجود داشته باشد، نقش آن به admin ارتقا می‌یابد. هیچ کاربر دیگری نمی‌تواند این نام کاربری را ثبت کند. حساب مالک از ثبت‌نام عمومی ساخته نمی‌شود؛ از طریق متغیرهای امن Render ایجاد می‌شود.

نام کاربری کاربران: ۳ تا ۲۴ نویسه انگلیسی، عدد یا زیرخط. رمز عبور: حداقل ۸ نویسه. خرید فقط پس از ورود/ثبت‌نام ممکن است.

## Render

- Build: `npm install`
- Start: `npm start`
- Environment variables را از `.env.example` در Render وارد کن.
- `SITE_URL` را با URL واقعی HTTPS سرویس جایگزین کن.
- `ADMIN_PASSWORD` و `SESSION_SECRET` را عوض کن و محرمانه نگه دار.

## درگاه

پیش‌فرض `PAYMENT_MODE=demo` است؛ هیچ پرداخت واقعی انجام نمی‌شود. پس از آنکه پذیرندگی مجاز و اطلاعات رسمی درگاه آماده شد، با راهنمایی سرپرست، Merchant ID را در Render وارد کن و درگاه را آزمایش و سپس فعال کن. مبلغ دیتابیس به ریال است. سرور پس از برگشت از درگاه، تراکنش را Verify می‌کند.

## محدودیت مهم

- KARENONE حساب مالک و مدیر سایت است؛ این حساب، خود ChatGPT یا یک هوش مصنوعی دائماً حاضر در سایت نیست.
- پیام‌ها یک صندوق پیام ساده بین مشتری و مدیر سایت هستند؛ پاسخ‌گویی خودکار هوش مصنوعی در این نسخه وجود ندارد.
- قبل از فروش، فقط قالب‌ها و فایل‌هایی را منتشر کن که خودت ساخته‌ای یا اجازه فروششان را داری.
- راه‌اندازی پذیرندگی و دریافت پول باید با کمک والد یا سرپرست و مطابق قوانین و شرایط سرویس پرداخت انجام شود.
